# Para reclutadores

Este proyecto demuestra ingeniería de agentes más allá de prompts:

- separación entre agente, skill, workflow y caso de negocio;
- contratos, schemas y tool allowlists;
- human-in-the-loop, aislamiento y límites de autorización;
- evaluaciones deterministas y modelo honesto de madurez;
- CLI, panel, Docker, CI y adaptación a un runtime real;
- diseño orientado a modernización, productos, educación y operación de repositorios.

La versión inicial declara `IMPLEMENTED`, no producción. El valor profesional está en la arquitectura verificable y en el mecanismo para incorporar evidencia real sin exagerar adopción.
