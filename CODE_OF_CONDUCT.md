# Código de conducta

> La participación debe ser respetuosa, técnica e inclusiva.

[Repositorio](README.md) · [Contribuir](CONTRIBUTING.md) · [Soporte](SUPPORT.md)

---

## Lo que se espera

- Criticar el trabajo, no a la persona que lo hizo.
- Argumentar con evidencia: un comando, un archivo o una fuente.
- Aceptar «no lo sé» y «me equivoqué» como respuestas válidas y valiosas.
- Dar contexto suficiente para que otra persona pueda continuar tu trabajo.

## Lo que no se tolera

- Acoso, insultos o ataques personales.
- Discriminación por cualquier característica personal.
- Publicar datos personales de otras personas, con o sin su consentimiento.
- Usar el proyecto o sus agentes para automatizar daño, vigilancia no consentida o suplantación.
- Presentar como demostrado algo que no se ha verificado, de forma deliberada.

## Alcance

Aplica a issues, pull requests, discussions, commits y cualquier espacio donde alguien represente al proyecto.

## Aplicación

Los mantenedores pueden editar, ocultar o eliminar contribuciones que incumplan estas reglas, y restringir la participación de quien las incumpla de forma reiterada.

Para reportar una conducta inadecuada, usa un canal privado del propietario del repositorio. Si el problema es una vulnerabilidad de seguridad y no una conducta, sigue [SECURITY.md](SECURITY.md).
