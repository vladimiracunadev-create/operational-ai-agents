# Despliegue local

> La forma más simple de explorar el catálogo: sin contenedor, sin API y sin costo.

[Repositorio](../../README.md) · [CLI](../../docs/CLI.md)

---

```bash
operational-agents serve
```

Abre `http://127.0.0.1:8765` para explorar contratos y generar planes deterministas.

El panel solo acepta loopback. Para usar los agentes de verdad, expórtalos al alcance de usuario o de proyecto de Claude Code:

```bash
operational-agents export claude --target ~/.claude/agents
```
