# Claude Code adapter

`operational-agents export claude` proyecta el contrato canónico a archivos compatibles con `.claude/agents/`. Usa la variante autónoma por defecto; `--preload-skills` agrega dependencias opcionales.

Las definiciones usan `model: inherit`, límite de turnos, memoria explícita, tool allowlists, permission mode y worktree para agentes mutantes.
