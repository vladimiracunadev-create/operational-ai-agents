# Guía de evidencia

Registra solo lo necesario para demostrar una decisión o resultado. Prefiere hashes, conteos, comandos y extractos mínimos antes que logs completos.

Nunca incluyas tokens, cookies, credenciales, datos personales, prompts privados, código de terceros confidencial ni URLs firmadas. Revisa manualmente todo artefacto antes de moverlo a `evidence/case-studies/`.

Un caso debe indicar agente/versión, objetivo, alcance, autorización, resultado, verificaciones, intervención humana, limitaciones y fecha. Las plantillas están en `evidence/templates/`.
