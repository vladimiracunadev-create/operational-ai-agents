# Modelo de madurez

## DRAFT

No instalable. Puede faltar contrato, evaluación o frontera de permisos.

## IMPLEMENTED

Manifiesto canónico, instrucciones, schemas, políticas, tres evals, exportación y CI sin errores.

## OPERATIONAL_LOCAL

Requiere una misión real ejecutada por el propietario, resultado aceptado, evidencia sanitizada, límites observados y retrospectiva. Un ejemplo sintético no califica.

## INTEGRATED

Requiere tools o servicios reales, autenticación correctamente acotada, prueba end-to-end, recuperación documentada y métricas mínimas.

## PRODUCTION_OBSERVED

Requiere uso recurrente, trazas, SLO o criterio de éxito, revisión humana, incidentes/limitaciones registrados y rollback probado.

La promoción se revisa mediante PR y evidencia; nunca la decide el propio agente.
